> [!TIP]
> **Key Takeaways / Tóm tắt nhanh cho Dev:**
> 1. **React Server Components (RSC)** chạy hoàn toàn trên server, giảm tối đa bundle JS gửi xuống browser.
> 2. Next.js 14 có **4 tầng Cache chính**: Request Memoization, Data Cache, Full Route Cache, và Router Cache.
> 3. Sử dụng `revalidateTag` và `revalidatePath` là cách hiệu quả nhất để làm mới dữ liệu mà không cần tải lại toàn bộ trang.

## 1. Giới thiệu App Router & Server Components

Từ Next.js 13+, **App Router** (`src/app/`) đã hoàn toàn thay thế Pages Router truyền thống. Mặc định, mọi component trong thư mục `app/` đều là **React Server Components (RSC)**.

### Tại sao Server Components lại quan trọng?

- **Zero Bundle Size**: Các thư viện nặng (như parse markdown, format ngày tháng, query database) được thực thi trên server và không bao giờ bị gom vào bundle JavaScript gửi xuống client.
- **Truy cập Backend trực tiếp**: Bạn có thể query PostgreSQL hoặc gọi nội bộ microservice ngay trong component mà không cần qua API route trung gian.

```tsx
// src/app/projects/page.tsx
// Đây là Server Component theo mặc định
import { db } from '@/lib/db';

export default async function ProjectsPage() {
  // Query trực tiếp DB tại Server
  const projects = await db.project.findMany({
    orderBy: { createdAt: 'desc' }
  });

  return (
    <div className="grid grid-cols-3 gap-6">
      {projects.map((project) => (
        <div key={project.id} className="p-4 bg-dark-secondary rounded-lg border border-dark-border">
          <h3 className="text-white font-fira">{project.title}</h3>
          <p className="text-text-secondary text-sm mt-2">{project.description}</p>
        </div>
      ))}
    </div>
  );
}
```

## 2. Làm chủ 4 Tầng Caching của Next.js 14

Hiểu rõ cơ chế Caching giúp ứng dụng của bạn đạt tốc độ phản hồi dưới **50ms**:

### 2.1. Request Memoization
Nếu bạn gọi cùng một hàm `fetch()` với cùng URL nhiều lần trong một chu kỳ render (chẳng hạn ở cả Layout và Page), Next.js sẽ tự động **memoize** kết quả để chỉ thực hiện 1 network request duy nhất.

### 2.2. Data Cache (Persistent Server Cache)
Dữ liệu trả về từ `fetch` được lưu giữ liên tục trên server cho đến khi bạn chủ động **revalidate**:

```tsx
// Tự động làm mới cache sau mỗi 3600 giây (1 giờ) - ISR
const res1 = await fetch('https://api.example.com/products', {
  next: { revalidate: 3600 }
});

// Hoặc sử dụng Tag-based Revalidation cho dữ liệu thời gian thực
const res2 = await fetch('https://api.example.com/cart', {
  next: { tags: ['cart-data'] }
});
```

## 3. Khi nào nên dùng `'use client'`?

Chỉ thêm chỉ thị `'use client'` ở trên cùng của file khi component cần:
- Dùng các React Hook như `useState`, `useEffect`, `useRef`, `useCallback`.
- Gắn các event listener (`onClick`, `onChange`).
- Sử dụng Browser API (`window`, `localStorage`, `navigator`).

### Nguyên tắc vàng:
> *"Để Server Component ở tầng trên cùng (Layout/Page), đẩy Client Component xuống các lá nhỏ nhất (Button, Modal, Input)."*
